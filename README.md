# Rz-skowo-Studio-Urody
Rzęskowo Studio Urody — Ekskluzywny Serwis WWW  Nowoczesna strona dla salonu urody Rzęskowo w jasnej palecie Warm Cream z akcentami Burgundy/Blue. Posiada animowane tło HTML5 Canvas, interaktywne karty usług połączone z galerią prac oraz profile zespołu. Serwis jest w pełni responsywny i zintegrowany z systemem rezerwacji Booksy.
